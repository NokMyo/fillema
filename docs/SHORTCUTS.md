# Fillema 단축키

| 범주 | 키 | 동작 |
|---|---|---|
| 재생 | `Space` | 재생 / 일시정지 |
| 재생 | `F` | 전체 화면 미리보기 |
| 컷 | `S`, `Ctrl+K` | 현재 위치 분할 |
| 컷 | `Delete` | 선택 클립 리플 삭제 |
| 컷 | `Q` | 현재 위치까지 앞 리플 트림 |
| 컷 | `W` | 현재 위치까지 뒤 리플 트림 |
| 컷 | `Ctrl+D` | 선택 클립 복제 |
| 컷 | `Ctrl+C` / `Ctrl+V` | 내부 클립 복사 / 붙여넣기 |
| 속성 | `C` | 기본 색보정 열기 |
| 속성 | `T` | 텍스트 추가 후 텍스트 속성 열기 |
| 작업 | `Ctrl+Z` / `Ctrl+Y` | 실행 취소 / 다시 실행 |
| 작업 | `Ctrl+P` | 명령 검색 |
| 파일 | `Ctrl+I` | 미디어 가져오기 |
| 파일 | `Ctrl+O` | 프로젝트 열기 |
| 파일 | `Ctrl+S` | 프로젝트 저장 |
| 파일 | `Ctrl+E` | 영상 출력 |

명령 검색에는 한글 이름과 영어 별칭이 함께 들어 있어 `노출`, `color`, `1080p`, `export`처럼 입력할 수 있습니다.
